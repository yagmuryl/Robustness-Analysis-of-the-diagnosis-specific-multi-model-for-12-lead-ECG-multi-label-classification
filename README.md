# Robustness-Analysis-of-the-diagnosis-specific-multi-model-for-12-lead-ECG-multi-label-classification
This project evaluates the reliability of the 12-lead ECG multi-label classification model by Cha et al. (2024) . We conduct robustness analysis using noise-injected datasets (Gaussian Noise, Baseline Wander) and cross-dataset validation to quantify performance decay in real-world wearable conditions.

Cardiovascular disease is one of the major causes of death worldwide. For this reason, automatic electrocardiogram (ECG) analysis is an important method for early diagnosis support and patient monitoring, especially in wearable health devices. In this study, the ResNet–DenseNet hybrid model with ResU blocks proposed by Hwang et al. and shared in the JaeBinCHA7 public repository is reproduced. The model is adapted for the AAMI-standard five-class heartbeat classification task using the MIT-BIH Arrhythmia Database.
On a held-out test set containing 21,892 heartbeats, the reproduced model reaches 98% overall accuracy and a macro F1-score of 0.89. The results show that the model performs well in general. However, class-based evaluation shows lower recall values for the minority and harder-to-distinguish classes, especially Supraventricular beats (S) with 0.66 recall and Fusion beats (F) with 0.64 recall. This performance drop is mainly related to class imbalance in the dataset rather than a limitation of the model architecture itself.
In addition, a noise-robustness analysis framework is introduced. This framework estimates how the F1-score of each class changes under simulated white Gaussian noise with signal-to-noise ratio values between −5 dB and 30 dB. The analysis helps identify critical SNR levels where minority classes begin to lose reliable performance and approach chance-level classification. Overall, this study provides a useful basis for evaluating whether ECG classification models can be used reliably in wearable devices, where signal quality may change significantly.
